# AED — Algoritmos e Estrutura de Dados

Repositório de estudos da disciplina de Algoritmos e Estrutura de Dados,
cursada em Engenharia da Computação na Universidade SENAI CIMATEC.

## Estrutura
- `Documentação/` — anotações das aulas
- `Exercícios/` — exercícios resolvidos em aula/casa
- `Ponteiro/` — exercícios de revisão de ponteiros
- `Struct/` — exercícios de struct/TAD
- `pilha.h` — implementação de pilha estática (em construção)

## Como compilar
gcc arquivo.c -o saida
